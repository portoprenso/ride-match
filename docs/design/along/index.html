DESIGN CONCEPT · 03 OCTOBER 2026

Good company. Same direction.

Along is a provisional brand for Ride Match. This local review covers the full mobile MVP. Buttons jump between illustrated states; forms, timers, permissions and external apps are simulated. The Figma file currently contains the brand kit and screens 01–20; further publishing was blocked by its Starter MCP quota.

Editable SVG exports retain text and vectors, but do not contain Figma components or prototype wiring. Local typography uses Manrope when installed, otherwise Avenir Next / Arial. Map artwork is illustrative.
